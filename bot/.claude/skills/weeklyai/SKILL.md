# Weekly AI 카드뉴스 봇

사내 직원용 주간 AI 카드뉴스(인스타 캐러셀형 540×720 HTML)를 **URL 소스 → 배포본**까지 만든다.
모든 스크립트는 `.claude/skills/weeklyai/scripts/`, 실행은 프로젝트 루트(`Weekly AI/`)에서.
`B=.claude/skills/weeklyai/scripts` 로 줄여 쓴다. 콘솔 한글 깨짐 방지로 Bash 에서 `export PYTHONIOENCODING=utf-8`.

**규칙의 정본은 루트 `카드뉴스_제작가이드.md`(§9-4 > §9-3 > §9-2 > §9-1 > §9 순으로 우선)와 `갑지_제작가이드.md`.** §9-4(VOL.34 고정 기준)는 반드시 읽는다.
아래 "절대 규칙"은 그 요약이다. 애매하면 가이드를 읽는다. 사용자가 새 기준을 주면 가이드에 반영한다.

> **★ 시작 전 필수 — 가이드 먼저 읽기.** 새 호든 수정이든, 어떤 스크립트를 돌리거나 문구를 쓰기 전에 **`카드뉴스_제작가이드.md` 전체와 `갑지_제작가이드.md` 를 Read 로 먼저 읽는다.** 이 요약만 보고 작업을 시작하지 않는다. 긴 파일은 나눠서라도 끝까지 읽는다.
>
> **★ 글을 쓸 땐 무조건 im-not-ai(humanize-korean) 스킬.** 표지 헤드라인·2p 소개·카드 제목·본문·갑지 문구 등 **사람이 읽는 글은 전부** 초안을 쓴 뒤 humanize-korean 스킬로 윤문하고 나서 `cards.py` 에 넣는다. `humanize_check.py` 경고 여부와 상관없이 매번 돌린다. 내용·수치·고유명사는 그대로.
>
> **★ 문맥을 끊지 않는다.** 문장을 짧게 뚝뚝 자르거나 줄마다 따로 노는 나열로 쓰지 말고, 연결어미로 앞뒤 문장을 이어 한 흐름으로 읽히게 쓴다. 윤문할 때도 문단 단위로 넣어 앞뒤 맥락을 함께 보게 한다(문장 하나씩 잘라 윤문 금지).

## 절대 규칙 (반려됐던 것들)

1. **장 구성 = 표지 + 소개(2p) + 바뀐 것 N장.** 마무리 장 없음. 한 주제 = 한 장(성능·가격 쪼개지 않음). "막 페이지 수를 늘리지마."
2. **링크·각주 없음.** "공식 페이지 바로가기", `'토큰'이란?` 같은 각주 블록 전부 금지. 출처는 `cards.py` 주석에만.
3. **수치는 원문 그대로.** 소수점 첫째 자리까지, 변화는 `A → B`, `%p` 대신 `%포인트`. 개념화("두 배 넘게", "거의 차이 없음") 금지. 우열 단정 대신 두 값을 나란히.
4. **말투 = 전문경영인이 초보자에게.** 담백한 존댓말 + 장마다 "그래서 왜 중요한가" 한 줄. 격언형 마무리, 훈계, "A보다 중요한 건 B", 과장 수식어, 과한 구어 금지.
5. **용어 표기:** ChatGPT(챗GPT ✗), 클로드 모델명은 영어(Opus·Sonnet·Haiku·Fable), '클로드'·'앤트로픽'은 한글. 가격(값·단가 ✗), 취약점(보안 구멍 ✗).
6. **제목**은 `모델명, 서술` 쉼표형(질문형 허용). **부제는 제목 요약이 아니라 정보 하나 더**(해석 한 줄), 날짜 X. 지금은 보통 부제 없이 감.
7. **2p 소개**: 숫자 나열 말고 "왜 이걸 보나" + 1~N 목록 + 결론 한 줄로 닫는다(마무리 장 대신).
8. **본문 = 문단 문자열, 줄바꿈은 봇이 (VOL.34, 가이드 §9-4 C-3).** `body=['문장. 문장. …']` 로 쓰면 `make_vol.py wrap()` 이 34자 폭에 고르게 나눈다(모델명 안 끊음, 줄 끝 외톨이 방지). 손으로 줄 나누기 금지. **6줄을 꽉 채운다**(짧으면 반려). 그림 숫자와 본문 숫자는 같은 기준. 기존 규칙: 한 줄 한글 34자 이내, 장당 6줄까지. 넘치면 **미디어 칸을 줄이지 말고 문구를 줄인다.** 너무 깎아서 가격·시간·조건이 빠져도 반려.
9. **미디어는 공식 자료만.** 공식 영상·이미지, 또는 공식 페이지 표·차트·카드를 **화면 그대로 캡처**. 직접 그린 HTML 표·패널·차트 금지. 인스타 "AI Generated" 이미지 금지. 신뢰 순서: 공식 페이지 자산 > 공식 유튜브 > 인스타 녹화본 상단 크롭.
10. **배지 카테고리**는 `AI트렌드` / `AI리터러시` / `Copilot 소식` 중 하나만(주제명 X).
11. **소스 계정의 프레임을 그대로 가져오지 않는다.** CTA("댓글 남기면…")·팔로우 장은 버리고, 우리 독자(사내 직원) 기준으로 컨셉을 바꾼다.
12. **속도.** 검증은 `check_vol.py` 하나(줄 길이 + 구조). 헤드리스 크롬 스크린샷으로 카드 넘침 확인하지 말 것(영상 때문에 안 끝남). 사용자가 브라우저로 직접 본다.
13. **배포는 "올려줘"를 들었을 때만**, 그러면 되묻지 않고 바로. 올리는 건 `weeklyaivolN.html` 하나(갑지 X).
14. **글쓰기 = 가이드 읽기 → 초안 → humanize-korean 윤문 → `cards.py`.** 윤문을 건너뛴 문구는 반려 대상이다. 문맥이 끊기는 단문 나열 금지(위 ★ 참고).

14. **레이아웃 고정 + 사진 꽉 채우기 (VOL.34, 가이드 §9-4 A·B).** 제목 위치·사진 칸(16:9)·본문 위치는 VOL.20번대 기본값 그대로. 장별 `aspect`, `EXTRA_CSS` 로 슬롯·제목·본문 바꾸기 **금지**. 미디어 파일은 **`media.py --fit16 [--y N]` 으로 16:9 로 잘라 칸을 꽉 채운다**(contain 여백 띠 금지). 인스타 720×960 녹화본은 `--fit16 --y 44`. `check_vol.py` 가 막는다.
15. **인스타 소스면 인스타를 그대로 따른다 (VOL.34 지시).** URL 의 `img_index` 번호만 바꿔 1~끝장 미디어를 전부 가져와(`fetch_insta.py` 가 한 번에 받음) **장 구성·제목·사진/영상은 인스타 그대로**, **본문만** 새로 쓴다. 팔로우·댓글 CTA 장만 버린다. 영상 장은 위쪽 화면만 크롭(§13, 720×510), 표지 이미지는 인스타 글자·워터마크 빼고 크롭. 이 규칙이 9·11번보다 우선.
16. **본문 = 전문경영인·기자 브리핑 (가이드 §9-4 C).** 사실·수치로 끝나는 단문. 해석·감상형("~이 보입니다", "~을 보여 줍니다", "단계입니다"), 감탄("놀랍", "!"), 구어 어미("~죠", "~네요") 금지 — `check_vol.py` 가 잡는다. 독자는 사내 임직원(수험생 → "수험생 자녀를 두신 임직원 여러분"), "국산" → "국내 AI", 표지 dek 기본 없음. **줄글로 잘 읽히게**: 짧게 뚝뚝 끊지 말고 연결어미로 문장을 이어 쓰고, 영어 번역식 어순·나열을 피한다(§9-4 C 3-1).

## 작업 순서

### 0. 가이드 읽기 → 다음 호 번호 정하기
**먼저 `카드뉴스_제작가이드.md`·`갑지_제작가이드.md` 를 끝까지 읽는다(건너뛰기 금지).** 그다음
`ls -d vol*` 에서 가장 큰 N + 1. 폴더 `volN/`, 원본은 `volN/원본/`.

### 1. 소스 읽기 (URL 종류별)
| 소스 | 방법 |
|---|---|
| 인스타 게시물 | `python $B/fetch_insta.py <URL> volN/원본` → `s01..` + `insta.json`(캡션). 로그인 벽이면 캡션만 나온다 → 사용자에게 **한 번만** `! python .claude/skills/weeklyai/scripts/fetch_insta.py --login` 을 부탁(창에서 로그인 후 닫기). 그 사이엔 캡션으로 컨셉 잡고 미디어는 공식 자료로 진행. |
| 공식 발표·제품 페이지 | WebFetch 로 본문 읽기 + `python $B/fetch_official.py scan <URL>` 로 영상(`assets.claude.com/*.mp4` 1080p)·유튜브·이미지 목록 |
| 유튜브 | `python $B/fetch_official.py yt <ID> volN/원본/x.mp4` (이 환경은 360p) |
| 뉴스 기사 | WebFetch 본문 → **기사 속 공식 원문을 찾아가** 수치·미디어는 공식 쪽에서 |
| Notion 공개 페이지 | 가이드 §13-5 `loadPageChunk` API |

- 인스타 영상은 대개 공식 영상의 녹화본이다 → 원본을 찾아 쓴다(가이드 §14). `media.py sheet` 로 콘택트시트를 떠서 어느 공식 영상의 몇 초인지 맞춘다.
- 수치·날짜는 **반드시 공식 원문에서** 확인한다. 인스타 자막·캡션 수치는 그대로 믿지 않는다.
- 외부 다운로드는 `curl --ssl-no-revoke` (사내망). 파이썬 urllib 는 인증서 오류.

### 2. 컨셉 정리 → 사용자에게 짧게 확인
"N가지" 구성, 카테고리, 표지 헤드라인 2줄 안, 장별 소스(어느 공식 페이지·영상)를 **표 하나로** 보여주고 바로 진행한다. 사용자가 이미 구성까지 정해 줬으면 확인 없이 진행.

### 3. 미디어 준비 (전부 `volN/` 안에, 깔끔한 한글 이름)
```bash
python $B/media.py video 원본/x.mp4 volN/모션 --ss 58 --to 70 --fit16   # → 모션.mp4 + 모션_poster.webp (무음, 폭 900, CRF 31)
python $B/media.py video 원본/s03.mp4 volN/장면 --fit16 --y 44   # 인스타 720×960 녹화본: 위쪽 화면 16:9 (VOL.34 기준)
python $B/media.py video 원본/mv.mp4 volN/노래1 --ss 39.5 --to 67 --sound   # 노래가 나와야 하는 장: 소리 유지 → cards.py media=('sound', '노래1')
python $B/capture.py <공식URL> --list "table, svg, figure"           # 캡처 후보 찾기
python $B/capture.py <공식URL> "table" volN/공식_벤치마크.webp --pad 12   # → 16:9 아니면 media.py img --fit16 으로 다시 자름
python $B/media.py img 원본/x.png volN/공식_요금표.webp --fit16 [--y N]   # 16:9 로 잘라 칸 꽉 채움, 폭 1500
```
- 표지는 보통 공식 영상의 인상적인 10초 구간(`표지영상`). 카드당 영상은 8MB 이하로.
- **노래·음악이 주제면 카드에서 실제로 소리가 나야 한다**(VOL.29 지시). 인스타 캐러셀 영상엔 오디오가 없으니 공식 MV를 `fetch_official.py yt` 로 받아 후렴만 `--sound` 로 자른다. 첫 클릭 뒤 장을 넘기면 자동으로 소리가 켜지고, 안 되면 ♪ 버튼. 가이드 §16.
- 캡처·이미지·영상이 16:9 가 아니면 **`--fit16 [--y N]` 으로 다시 자른다.** `cards.py` 에 `aspect` 를 적지 않는다(§9-4).

### 4. `volN/cards.py` 작성
`.claude/skills/weeklyai/template/cards_example.py`(= VOL.28 실제 사양)를 복사해서 고친다. 한 파일에 표지·장·테마·갑지가 다 들어간다.
최신 기준(§9-4) 문구·구성은 `.claude/skills/weeklyai/examples/vol30~34/cards.py` 를 참고한다(가장 최근 호가 기준). 새 호를 확정하면 그 `cards.py` 도 `examples/volN/` 에 복사해 둔다.
- `THEME`: 직전 호와 다른 색으로. 프리셋 `plum`(VOL.28)·`forest`(VOL.27)·`night`(VOL.29), 또는 `scripts/wai.py ROLES` 의 20개 역할에 색을 주는 dict(어두운 배경 3단 + 밝은 글자 + 강조색 2 + 보조색). 주제 브랜드 색(공식 페이지 하이라이트)에서 고른다.
- 표지 `css` 의 `rgba(13, 8, 11, …)` 그라데이션은 테마 배경색(`card_bot`)에 맞춰 바꾼다.

### 5. 생성 → 검사 → 빌드
```bash
python $B/make_vol.py N && python $B/check_vol.py N
python $B/humanize_check.py N      # 본문 AI 티 점검(im-not-ai 진단). 윤문은 경고와 상관없이 항상 한다(아래)
python $B/media.py cover volN/표지영상.mp4 volN/coverN.webp --at <초>   # 갑지 배경 (33:25)
python $B/make_gabji.py N && python $B/build_vol.py N
```
- **본문 윤문 = humanize-korean 스킬**(`.claude/skills/humanize-korean`, epoko77-ai/im-not-ai). **모든 글(표지·소개·제목·본문·갑지 문구)은 경고 여부와 상관없이 매번 이 스킬로 윤문한 뒤** `cards.py` 에 넣는다 — 내용·수치·고유명사 불변, 문단 단위로 넣어 문맥이 끊기지 않게, 결과는 34자·6줄로 다시 줄바꿈. 윤문 뒤 `humanize_check.py` 로 다시 확인.
- `check_vol.py` 가 문제를 내면 `cards.py` 문구를 고쳐 다시. 통과하면 **바로 보고**.
- `build_vol.py` 가 `weeklyaivolN.html`(배포본, base64 내장)과 `weeklyai_갑지_volN.html`(PNG 저장용)을 만든다.

### 6. 보고
- 장별 한 줄 요약(제목 + 미디어 출처), 배포본 크기, 테마, 확인할 로컬 파일 경로(`volN/weeklyaivolN.html`).
- 판단이 들어간 곳(수치를 어느 원문에서 가져왔는지, 버린 인스타 장)을 짧게.
- 갑지는 배포본을 브라우저로 열어 PNG 저장 버튼으로 받는다고 안내.

### 7. 수정 요청
문구·순서·장 수 수정은 **`cards.py` 만 고치고 5단계를 다시** 돌린다(`_src.html` 직접 편집 금지 — 다음 생성 때 덮어써짐). 사용자가 문구를 직접 주면 그대로 넣고, 줄이 넘칠 때만 줄바꿈 위치를 조정한 뒤 알린다.

### 8. 배포 ("올려줘")
```bash
python $B/publish.py N      # KIKEUN/weeklyai 루트에 weeklyaivolN.html 하나, sha 대조까지
```
URL: `https://kikeun.github.io/weeklyai/weeklyaivolN.html`. 이 PC는 외부 HTTP 확인이 막혀 있으니 `gh api repos/KIKEUN/weeklyai/pages/builds/latest --jq .status` 로 빌드만 확인.
