# Weekly AI 카드뉴스 작업 폴더

이 폴더는 사내 주간 AI 카드뉴스(Weekly AI)를 만드는 곳이다. 사용자가 인스타·공식 발표·뉴스·유튜브 URL을 주거나 "weeklyai 만들자", "volN 만들어", "올려줘"라고 하면 **`weeklyai` 스킬**(`.claude/skills/weeklyai/SKILL.md`)로 처리한다.

## 반드시 지킬 것
1. **작업 전에 `카드뉴스_제작가이드.md` 와 `갑지_제작가이드.md` 를 끝까지 먼저 읽는다.** 요약이나 기억만으로 시작하지 않는다.
2. **글(표지·소개·제목·본문·갑지 문구)을 쓸 땐 무조건 im-not-ai(`humanize-korean` 스킬)로 윤문**한 뒤 `cards.py` 에 넣는다. 내용·수치·고유명사는 그대로.
3. **문맥을 끊지 않는다.** 단문을 뚝뚝 자르지 말고 연결어미로 이어 한 흐름으로 쓴다.
4. 배포는 사용자가 "올려줘"라고 했을 때만.

## 처음 쓰는 사람
`설치.bat` 을 한 번 실행해 파이썬 패키지와 Chrome·node·gh 를 확인한다. 자세한 건 `README.md`.
