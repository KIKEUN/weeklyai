## 1. 핵심 규칙 (이것만 지키면 됨)

1. **크기(비율)** = **1274 × 971 px (33 : 25, 가로형)**. 화면에 맞춰 자동 축소되지만 **비율은 항상 고정**.
2. **1호 = 1장.** 이전 호를 같이 넣지 않는다. 넘기기·화살표·`n / N` 카운터 **전부 없음**.
3. **가져올 것 = 배경 + 제목뿐.**
   - ✅ 배경(표지 이미지 / 영상 첫 프레임 / 테마 그라데이션)
   - ✅ 제목(헤드라인) + 강조(mark) + 짧은 부제(dek, 있으면)
   - ✅ VOL 뱃지 = `VOL.N ｜ <카테고리>`. 카테고리는 **AI트렌드 / AI리터러시 / Copilot 소식** 3개 중 하나만 (주제명 X). 예: `VOL.17 ｜ AI트렌드`
   - ❌ Weekly AI 워드마크(ai54.png) **넣지 않음**
   - ❌ AI디자인랩 로고/푸터 **넣지 않음**
   - ❌ 인덱스 칩·본문 등 나머지 **넣지 않음**
   - ⚠️ 단, **브랜드 로고가 표지 콘셉트의 핵심**이면 넣음 (§5 로고 워터마크 옵션)
4. **레이아웃 = 정중앙 정렬.** 모든 글자·요소는 가로·세로 중앙, 가운데 정렬.
5. **가독성 최우선.** 배경 위에 스크림(어둠막) + 글자 그림자.
   강조색(mark)은 **투명 그라데이션 금지 → 선명한 단색 + 그림자**.

## 5. 배경 자산 확보 방법

> 이 환경: python·pip OK, PyPI OK, ffmpeg는 `imageio-ffmpeg`로 확보.
> 사내망 TLS 가로채기 때문에 외부 다운로드는 **인증서 검증 끄고** 받아야 함:
> `ctx=ssl.create_default_context(); ctx.check_hostname=False; ctx.verify_mode=ssl.CERT_NONE`

### A. 1페이지 내장 이미지 추출 (base64 → 파일)
```python
import re, base64
s=open("weeklyaivolN.html",encoding="utf-8",errors="ignore").read()
seg=re.search(r'id="hcn-card-1".*?</section>',s,re.S).group(0)
imgs=sorted(re.findall(r'data:image/(\w+);base64,([A-Za-z0-9+/=]+)',seg),
            key=lambda x:len(x[1]),reverse=True)
ext,d=imgs[0]; open(f"coverN.{ext}","wb").write(base64.b64decode(d))
```
⚠️ 첫 이미지가 `Weekly AI 워드마크(ai54)`인 경우가 많다. **추출 후 눈으로 확인**.

### B. 가로형(33:25)으로 다시 자르기
```python
from PIL import Image
im=Image.open("원본.png").convert("RGB")
crop=im.crop((0,0,620,470))                      # 문구·UI 제외한 영역
crop.resize((1274,971),Image.LANCZOS).save("coverN.webp","WEBP",quality=88,method=6)
```

### C. 영상 첫 프레임 → 배경
```python

FF=imageio_ffmpeg.get_ffmpeg_exe()
```

## 6. HTML 골격 & 배포본 빌드

```html
<div class="cover cover--v17" id="cover" data-vol="17">
  <div class="cover__bg"><img src="cover17.webp" alt="" /></div>   <!-- 이미지 없으면 이 줄 삭제 → 그라데이션 -->
  <div class="cover__scrim"></div>
  <div class="cover__center">
    <span class="badge">VOL.17 ｜ AI트렌드</span>   <!-- 카테고리 3종 중 하나: AI트렌드 / AI리터러시 / Copilot 소식 -->
    <h1 class="headline">GOOGLE의 깜짝 발표<br /><span class="mark">GEMINI</span> 신모델 출시</h1>
    <p class="dek">새 모델 셋을 한꺼번에, 그런데 기다리던 Pro는 또 빠졌습니다</p>  <!-- 없으면 삭제 -->
  </div>
</div>
```

새 호는 `weeklyai_갑지_vol17_src.html`을 복사해 **`data-vol`, `cover--vNN` 클래스, 글자, `--` 변수**만 바꾸면 된다.

```python
# 배포본 빌드 (이미지 내장)
import re, base64, os
src=open("weeklyai_갑지_volN_src.html",encoding="utf-8").read()
MIME={".webp":"image/webp",".png":"image/png",".jpg":"image/jpeg"}
def repl(m):
    fn=m.group(3)
    if fn.startswith(("http","data:")) or not os.path.exists(fn): return m.group(0)
    b=base64.b64encode(open(fn,"rb").read()).decode()
    return f'{m.group(1)}{m.group(2)}data:{MIME[os.path.splitext(fn)[1].lower()]};base64,{b}{m.group(2)}'
out=re.sub(r'(\bsrc=)(["\'])([^"\']+)\2',repl,src)
open("weeklyai_갑지_volN.html","w",encoding="utf-8").write(out)
print("남은 로컬 참조:", re.findall(r'src="(?!data:|https?:)([^"]+)"',out))   # → [] 이어야 정상
```

## 7. ★ PNG 저장 (1274 × 971) — 캔버스 직접 그리기

**`html2canvas` 금지, SVG `foreignObject` 금지.**
- `html2canvas`: 컨테이너 쿼리 단위(`cqw`/`cqh`)를 렌더 못 해 레이아웃이 깨진다.
- `foreignObject`: 브라우저·CSS 조건을 심하게 타서 **그냥 안 되는 경우가 많다.** (실제로 실패해서 폐기)

→ **캔버스 2D에 직접 그린다.** 항상 1274×971로 정확히 나오고, 웹폰트도 `document.fonts.ready` 이후면 그대로 쓰인다.

**지켜야 할 규칙 — 이걸 어기면 화면과 PNG가 달라진다.**

1. **색·그라데이션은 전부 `.cover`의 CSS 변수로 둔다.** JS가 `getComputedStyle`로 읽어 캔버스에 같은 값을 그린다.
   ```
   --accent  --bg-a --bg-b --bg-c
   --scrim-top --scrim-mid --scrim-bot   (linear-gradient 180deg, 0% / 26% / 100%)
   --vig-in --vig-out                    (radial-gradient 118% 92% at 50% 46%, 24% / 100%)
   ```
   호별 테마는 **이 변수만 override**한다. 새 그라데이션을 CSS에 직접 쓰면 PNG에 반영되지 않는다.
2. **치수는 `cqw`/`cqh`로만 쓴다.** JS가 `CQW = 1274/100`, `CQH = 971/100`으로 환산해 같은 값을 계산한다.
   현재 매핑: 뱃지 `1.7cqw` / 헤드라인 `7cqw`(line-height 1.2) / mark `1.06em` / dek `2.1cqw`(1.5) / 요소 간격 `3.4cqh`.
   **CSS에서 이 숫자를 바꾸면 JS 상수도 같이 바꿔야 한다.**
3. 헤드라인은 `<br>`로 줄을 나누고 강조는 `<span class="mark">`로만 표시한다. JS가 이 구조를 그대로 파싱한다.
4. 배경 이미지는 `object-fit: cover` 기준으로 그린다 (JS도 동일하게 `max(W/iw, H/ih)` 스케일).
5. **저장 실패 시 90%는 `_src`(로컬 이미지)에서 눌렀기 때문.** 배포본에서 열 것. (§2)

파일명은 `WeeklyAI_VOL{data-vol}_갑지.png`로 떨어진다.
