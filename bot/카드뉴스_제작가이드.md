## 0. 한눈에 보기 (TL;DR)

- **봇 사용**: `/weeklyai <인스타·공식 발표 URL>` → `volN/cards.py` 한 파일에 내용을 쓰고 스크립트가 HTML·갑지·배포본을 만든다 (§15).
- **단일 HTML 파일** 1개로 완성 (`weeklyaivolN.html`). 외부 의존성 = Pretendard 폰트 CDN, 표지 로고 `kikeun.github.io/weeklyai/assets/ai54.png` 뿐.
- **CSS-only 캐러셀** — 라디오 버튼 + `:checked ~ 형제` 선택자로 슬라이드 전환. JS는 라이트박스(클릭 확대)와 초기화용 최소한만.
- 카드 규격 **540 × 720 (3:4)**, 인스타 캐러셀용.
- 이미지/영상은 같은 폴더에 두고 **반드시 용량 최적화** 후 사용 (깃허브 배포).
- 글은 **한국어, 쉬운 말**. 전문용어는 본문 안에서 풀어 쓴다 (**각주·링크 금지**, §9-3).
- 장 수는 **표지 + 소개 + 바뀐 것 N장 = N+2장**. 마무리 장 없음, 한 주제를 두 장으로 쪼개지 않음 (§9-3).

## 3. 카드 템플릿

### 3-1. 표지 (card 1)

```html
<section class="card card--cover" id="hcn-card-1" aria-label="슬라이드 1 표지">
  <div class="card-bg"></div>
  <img class="cover-media-img" src="갑지.webp" alt="" loading="eager" decoding="async" />
  <div class="cover-bottom-deco" aria-hidden="true"></div>
  <div class="card-content card-content--cover">
    <span class="cover-badge cover-badge--top">VOL.11 ｜ AI트렌드</span>   <!-- 배지 = 카테고리 3종 중 하나 (아래 참고) -->
    <div class="cover-inner">
      <div class="cover-top">
        <figure class="cover-figure"><img src="https://kikeun.github.io/weeklyai/assets/ai54.png" alt=""></figure>
      </div>
      <div class="cover-hero-wrap"><div class="cover-hero">
        <h1 class="cover-headline">
          <strong>Anthropic 역대 최강 모델</strong><br />
          <strong class="cover-headline__mark">Claude 5</strong>
        </h1>
        <p class="cover-dek">Fable 5와 Mythos 5에 대해 알아보아요</p>
      </div></div>
    </div>
    <div class="footer"> ...로고+AI디자인랩... </div>
  </div>
</section>
```

표지 핵심 포인트:
- **풀블리드 이미지**: `.cover-media-img`가 카드 전체를 `object-fit:cover`로 채움.
- **이미지를 줄여도 테두리 안 보이게**: `#hcn-card-1 .card-bg { background: <이미지 가장자리색>; }` 로 배경을 이미지 배경색과 맞춘 뒤 `transform: scale(0.88)` 등으로 축소. (이미지 가장자리 색 추출법은 §6 참고)
- **상단 배지 = 카테고리 (★중요)**: `cover-badge--top` (절대배치 top:14px left:16px). 형식 = `VOL.N ｜ <카테고리>`.
  - 카테고리는 **반드시 아래 3개 중 하나**만 씁니다. 매 호는 이 셋 중 하나에 속합니다:
    | 카테고리 | 다루는 내용 | 배지 예시 |
    |---|---|---|
    | **AI트렌드** | 새 모델·기능 출시, 업계 소식 등 트렌드 | `VOL.17 ｜ AI트렌드` |
    | **AI리터러시** | AI 활용법·개념·교육성 콘텐츠 | `VOL.N ｜ AI리터러시` |
    | **Copilot 소식** | 마이크로소프트 코파일럿 관련 소식 | `VOL.N ｜ Copilot 소식` |
  - ⚠️ **주제명(제미나이·클로드 등)은 배지에 넣지 않습니다.** 배지엔 카테고리만, 주제는 헤드라인·본문에서 다룹니다.
    (예: vol17은 제미나이+클로드를 다루지만 배지는 `VOL.17 ｜ AI트렌드`)
- **로고(ai54.png)**: `cover-top`에 배치, `object-position:left top`. 위치는 `cover-top { padding-top }` 로 조절.
- **헤드라인**: `<strong>`=흰색, `.cover-headline__mark`=그라데이션 강조.
- **dek**: 헤드라인 아래 작은 안내 문구.

## 4. ★ 카드 수 바꾸기 (가장 실수 많은 부분)

카드를 **N장**으로 맞추려면 아래 **8곳**을 전부 N에 맞춰야 한다. 하나라도 빠지면 네비/도트가 어긋남.

| # | 위치 | 규칙 |
|---|---|---|
| 1 | 라디오 인풋 | `hcn-nav-1` ~ `hcn-nav-N` (첫 번째만 `checked`) |
| 2 | CSS 표시 블록 | `#hcn-nav-K:checked ~ .carousel-row #hcn-card-K` 를 K=1..N |
| 3 | CSS prev | `nav-prev-from-2`~`nav-prev-from-N` + `nav-prev-disabled`는 nav-1에 |
| 4 | CSS next | `nav-next-from-1`~`nav-next-from-(N-1)` + `nav-next-disabled`는 **nav-N**에 |
| 5 | HTML prev 라벨 | `disabled` 1개 + `from-2`(→nav-1) ~ `from-N`(→nav-(N-1)) |
| 6 | HTML next 라벨 | `from-1`(→nav-2) ~ `from-(N-1)`(→nav-N) + `disabled` 1개 |
| 7 | HTML 도트 | `<span class="dot">` N개 |
| 8 | CSS 도트 활성 | `#hcn-nav-K:checked ~ .progress-dots .dot:nth-child(K)` 를 K=1..N |

**검증 스크립트** (수정 후 반드시 실행 — 모든 줄이 1..N로 깔끔해야 정상):
```bash
python -c "
import re
h=open('weeklyaivolN.html',encoding='utf-8').read()
print('nav   :', sorted(set(re.findall(r'id=\"hcn-nav-(\d+)\"',h)),key=int))
print('card  :', sorted(set(re.findall(r'id=\"hcn-card-(\d+)\"',h)),key=int))
print('prev  :', sorted(set(re.findall(r'nav-prev-from-(\d+)',h)),key=int))
print('next  :', sorted(set(re.findall(r'nav-next-from-(\d+)',h)),key=int))
print('dots  :', h.count('<span class=\"dot\">'))
print('visib :', len(re.findall(r'#hcn-nav-\d+:checked ~ .carousel-row #hcn-card-\d+',h)))
print('dotcss:', sorted(set(re.findall(r'dot:nth-child\((\d+)\)',h)),key=int))
"
```
기대값: nav/card/dotcss = 1..N, prev = 2..N, next = 1..(N-1), dots = N, visib = N.

## 6. ★ 이미지 / 영상 용량 최적화 (깃허브 배포 필수)

원본은 보통 과도하게 큼(2000~4000px, 영상 수십 MB). 카드 표시 크기(~540px)에 맞게 줄인다.

### 이미지 (Python / Pillow)
```bash
python -c "
from PIL import Image; import os
name='효율.webp'; maxw=1500; q=82
im=Image.open(name).convert('RGB'); w,h=im.size
nw=min(maxw,w); nh=round(h*nw/w)
im.resize((nw,nh),Image.LANCZOS).save('_opt.webp','WEBP',quality=q,method=6)
print(f'{w}x{h} {os.path.getsize(name)//1024}KB -> {nw}x{nh} {os.path.getsize(\"_opt.webp\")//1024}KB')
"
# 확인 후: mv -f _opt.webp 효율.webp
```
- 일반 사진/그래프: 폭 1500, q82. 표(글자 많음): 폭 1500 유지(가독성).

### 영상 (시스템 ffmpeg 없을 때 → imageio-ffmpeg 사용)
```bash
pip install imageio-ffmpeg -q
FF=$(python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
"$FF" -y -i 원본.mp4 -an -vf "scale=900:-2" -c:v libx264 -preset slow -crf 31 -movflags +faststart -pix_fmt yuv420p _c.mp4
# 확인 후: mv -f _c.mp4 원본.mp4
```
- `-an`(무음, 어차피 muted), 폭 900, CRF 31 → 대략 **1/10 이하**로 감소.
- 50초처럼 긴 영상이 여전히 크면 핵심 구간만 잘라 짧은 루프로.

### 배경색 매칭용 — 이미지 가장자리 색 추출
```bash
python -c "
from PIL import Image
im=Image.open('갑지.webp').convert('RGB'); w,h=im.size
for k,(x,y) in {'TL':(8,8),'Tmid':(w//2,8),'Lmid':(8,h//2)}.items():
    print(k,'#%02x%02x%02x'%im.getpixel((x,y)))
"
```

## 7. 미디어 슬롯 채우기 규칙

> **VOL.34부터 §9-4 A 가 이 절보다 우선**: 슬롯은 16:9 고정, 미디어 파일을 `media.py --fit16` 으로 16:9 로 잘라 **꽉 채운다**. contain(여백 띠)·장별 aspect 금지. 아래 contain·aspect 안내는 VOL.33 이전 기록.

- 슬롯 비율 = **16:9** (고정).
- **사진/영상**: 16:9 로 잘라 기본 `object-fit:cover` 그대로.
- (구) 표·요금제·정사각형 그래프: 해당 카드에 `object-fit:contain` override — **VOL.34부터 금지**, 필요한 부분을 16:9 로 잘라 쓴다.
- 모든 슬롯 이미지는 **클릭하면 확대**(라이트박스, §8). 영상은 확대 대상 아님.
- 미디어는 **공식 페이지의 실제 이미지·영상·화면 캡처만** 쓴다. 직접 그린 HTML 표·패널·차트 금지 (VOL.26).
- ★ **문구가 카드에 안 들어가면 미디어 칸을 줄이지 말고 문구를 줄인다** (VOL.27). 영상 칸을 16:9로 줄이려다 "문구를 줄여, 영상 16:9로 줄이지 마"로 반려됨.
- (구, VOL.34부터 금지) 소스 영상 비율이 16:9가 아니면 슬롯을 그 비율에 맞춘다. 예) VOL.27 인스타 영상 상단 720×510 → `.slide-media-slot { aspect-ratio: 720 / 510; }` + `object-fit: contain`. 이때 본문 공간은 약 **5줄 + 링크 1줄**(15.5px 기준)이 한계.

## 9. 콘텐츠 작성 원칙

1. **출처 명확히**: 본문 사실/수치는 사용자가 준 원문(공식 발표/뉴스)에 근거. 인스타 등은 OCR이 부정확하니 텍스트/원문 URL을 받아서 작성.
2. **쉬운 한국어**: 전문용어(SOTA, 벤치마크명 등) 지양 → 풀어 쓰거나 각주.
3. **줄바꿈**: `<br />`로 직접. 문단 사이 빈 줄(`<br /><br />`)은 보통 안 씀(요청 시 제거).
4. **카드 1장 = 메시지 1개**. 본문 5~6줄 내외.
5. **표지**: 배지(`VOL.N ｜ 카테고리` — 카테고리는 AI트렌드/AI리터러시/Copilot 소식 중 하나, §3-1 참고), 헤드라인(굵게+강조색), dek(작은 안내).
6. **사람이 쓴 것처럼 (★AI 티 제거)**: AI가 쓴 듯한 문구는 사람이 쓴 것처럼 다시 다듬는다.
   - 피할 것: "~에 대해 알아보아요", "함께 살펴봅시다", "~할 수 있습니다"의 반복, "혁신적/강력한/놀라운" 같은 과장 수식어, 기계적인 병렬·과한 존댓말투, 이모지 남발.
   - 지향: 짧고 담백한 구어체, 핵심만 콕. 예) "성능이 향상되었습니다" → "성능이 올랐습니다" / "제공될 예정입니다" → "곧 풀립니다".
   - 작성 후 소리 내어 읽어 어색하면 고친다.

## 9-1. ★ 문구 작성 기준 (VOL.23 검토 반영 — 이 절이 §9보다 우선)

> 2026-09-07 vol23에서 매니저·팀장 검토를 거치며 확정된 기준.
> **초안이 §9의 "쉬운 한국어"만 좇다가 수치를 뭉개서 전부 되돌아왔다.**
> 새 호를 쓸 때 아래를 그대로 따를 것.

### A. 수치는 원문 그대로 쓴다 (★ 가장 많이 틀린 곳)

"쉽게 쓴다"를 **숫자를 뭉개는 것**으로 착각하지 말 것. 어려운 건 *용어*지 *숫자*가 아니다.

| ❌ 개념화(반려됨) | ✅ 원문 수치 |
|---|---|
| 터미널 코딩은 42%에서 **56%**로 | 터미널 코딩 평가는 **42.0% → 55.8%** |
| 과학 과제는 **두 배 넘게** 올랐습니다 | 과학 문제 해결 평가는 **24.7% → 52.6%** |
| 오퍼스 5와 **거의 차이가 없습니다** | 두 모델의 차이는 **0.3%포인트**에 불과했습니다 |
| 제미나이 플래시보다 **훨씬 비쌉니다** | 제미나이 플래시의 **약 13배**입니다 |
| 예전엔 **10km 단위로 뭉개지던** 지형이 | 해상도는 **10~20km에서 2~3km로** 개선됐습니다 |
| 1990년대 **나사 탐사선** | 1990년대 **나사 마젤란 탐사선** (고유명사 살릴 것) |

- 소수점 첫째 자리까지 그대로. `42%` ✗ → `42.0%` ○
- 변화는 `A → B` 화살표 표기로 통일.
- **`%p` 금지 → `%포인트`** 로 풀어 쓴다.

### B. 단어 선택

| ❌ | ✅ | 비고 |
|---|---|---|
| 값, 단가, 표시 단가 | **가격** | 일상어로 |
| 챗GPT | **ChatGPT** | 제품명은 원표기 |
| 동일한 엔진 / 바탕이 같다 | **같은 기반 모델** | |
| 3대 클라우드 | 클로드 앱 **등** (나열 대신 축약) | |
| 보안 구멍 | **취약점** | 정식 용어가 더 짧고 통함 |
| 장시간 자율 수행 | 사람이 계속 지켜보지 않아도 **여러 단계를 이어서 처리** | 조어 금지, 풀어 쓰기 |

### C. 판단은 독자에게 — 우열 단정 대신 병렬 제시

```
❌ 3.8 플래시가 89.4%를 받아 더 비싼 클로드 오퍼스 5(89.1%)를 앞섰습니다.
✅ 터미널 코딩 평가에서 3.8 플래시는 89.4%,
   클로드 오퍼스 5는 89.1%를 기록했습니다.
```
제목도 마찬가지. `3.8 플래시가 오퍼스 5를 앞섰습니다` → **`3.8 플래시, 오퍼스 5와 성능 비슷?`**

### D. 제목·부제

- **제목**: `모델명, 서술` 쉼표형을 기본으로. 질문형(`~비슷?`)도 허용.
  - `페이블 5.1, 가격은 그대로입니다` / `아스트라와 페이블 5.1, 가격은 같습니다` / `세 모델, 잘하는 일이 다릅니다`
- **부제는 제목의 요약이 아니라 정보를 하나 더 준다.**
  - 제목 `오픈AI, GPT-6 아스트라 출시` + 부제 `추론·코딩에 컴퓨터 조작 능력까지 강화` ○
  - 제목 `오픈AI, GPT-6 아스트라 출시` + 부제 `세 회사 가운데 마지막입니다` ✗ (정보 없음)
- 부제에 **날짜를 넣지 않는다.** 날짜는 본문 첫 문장에.

### E. 인트로(2p)와 마무리(마지막 장)

- 인트로는 사실 나열로 끝내지 말고 **이번 호의 관전 포인트**를 한 줄로 제시.

- 마무리는 표만 놓지 말고 **판단 기준 한 줄**로 닫는다.
  > 모델 성능이 비슷해질수록 무슨 일을 맡길지가 더 중요해집니다.

### F. 차트를 가리킬 때

- 카드 구조가 `제목 → 미디어 → 본문` 이므로 차트는 본문 **위**에 있다. → **"위 차트"** ("아래 그래프" ✗)
- 차트만 보고 못 읽는 문장은 쓰지 말 것. 차트 안에 한글 제목·축이름·읽는 법을 넣고, 본문은 결론만 말한다.

### G. 줄 길이 (★ 레이아웃 깨짐 방지)

본문 한 줄은 **한글 34자 이내**(영숫자는 0.6자로 계산). 넘으면 카드에서 자동 줄바꿈돼 본문이 6~7줄로 늘어나 아래로 밀린다.

```python
# 작성 후 반드시 실행
import io, re, html as H
h = io.open('weeklyaivolN_src.html', encoding='utf-8').read()
for k in range(2, 13):
    s = re.search(r'<section class="card" id="hcn-card-%d"(?:.|\n)*?</section>' % k, h)
    if not s: continue
    b = re.search(r'<div class="slide-bottom-copy">(?:.|\n)*?</span>', s.group(0)).group(0)
    for l in b.split('<br />'):
        t = H.unescape(re.sub(r'<[^>]+>', '', l)).strip()
        if not t: continue
        w = sum(1.0 if ord(c) > 0x1100 else 0.6 for c in t)
        if w > 34.5: print('%2dp %.0f자: %s' % (k, w, t))
```

## 9-2. ★ 문구 확정 과정에서 나온 기준 (VOL.27 "주말에 따보는 AI 자격증 8가지")

> 초안 → 사용자 장문안 → 사용자 축약안 → 최종본까지 4번 돌았다. 아래가 그 과정에서 확정된 기준.

### A. 분량: 너무 줄여도, 너무 길어도 반려
| 시도 | 결과 |
|---|---|
| 본문 4~5줄 + 수치 다수 (초안) | 통과에 가까움 |
| 장문 문단 8~10줄 | 카드에 안 들어감 → 미디어를 줄이지 말고 **문구를 줄일 것** |
| 3줄로 압축 (가격·문항·유효기간 삭제) | "**너무 줄였다**" — 가격·시간 같은 정보가 빠지면 안 됨 |
| **4~5줄, 수치는 살리고 말투만 담백하게** | ✅ 최종 |

→ 자격증·제품 소개 장에는 **비용 / 소요시간 / 문항 수 / 유효기간 / 언어** 중 원문에 있는 건 남긴다.

### B. AI 티 나는 문구 → 바꾼 예
| ❌ | ✅ |
|---|---|
| 그 경험이 결국 AI 역량의 차이를 만듭니다. (격언형 마무리) | 따기 쉬운 자격증부터, 배운 걸 한 번 써보는 걸로 시작해보세요. |
| 자격증보다 중요한 건 배운 것을 업무에 써보는 것입니다. | (같은 이유로 삭제 — "A보다 중요한 건 B" 구조 금지) |
| AI 역량은 누가 대신 키워 주지 않습니다. | 삭제 (훈계조) |
| 한국어판이 따로 있어서 영어 걱정은 안 해도 됩니다. (너무 구어) | 한국어판이 따로 있어 쉽게 접근할 수 있습니다. |
| 고르는 기준은 하나, 이번 주말에 낼 수 있는 시간입니다. | (인트로는 개념 제시로 교체, 아래 C) |

- 말투는 **담백한 존댓말**. 격언·훈계·"A보다 중요한 건 B"·과한 구어("걱정 안 해도 됩니다") 둘 다 피한다.
- 수치·고유명사는 그대로 두고 **문장 뼈대만** 사람 말처럼 바꾼다.

### C. 인트로(2p)는 "왜 이걸 보나"를 말한다
- 숫자 나열(무료 4·유료 4, 99~150달러, 기준일…)로 채우지 않는다. 구성 안내는 **한 줄**이면 충분.
- 최종본:
  > AI를 써보긴 했는데 어디서부터 제대로 배울지 막막하다면,
  > 자격증 과정을 통해서 배워보는 것도 좋은 방법입니다.
  > 따라가다 보면 자연스럽게 AI 역량이 증가합니다.
  > 이번 호에서는 **무료 4개, 유료 4개**를 담았습니다.

### D. 컨셉 방향
- "이력서에 쓰는 자격증"(원 소스의 프레임) → **"주말을 활용해 따보는 / 내 역량을 늘려보는"** 으로 바꿔 달라는 요청. 소스 계정의 프레임을 그대로 가져오지 말고 **우리 독자(사내 직원) 기준**으로 바꾼다.

### E. 기타
- ~~"공식 페이지 바로가기 →" 링크는 소개 대상이 있는 장에만.~~ → **VOL.28부터 링크 자체를 넣지 않는다** (§9-3).
- 한 문장이 34자 안팎으로 한 줄에 들어가면 **억지로 쪼개지 말 것** (예: "리더 71%는 경력이 적어도 AI를 잘 쓰는 사람을 뽑겠다고 답했습니다." 한 줄).

## 9-3. ★ VOL.28 확정 기준 (2026-10-12 "클로드 업데이트 4가지") — §9-1·9-2보다 우선

> 초안(8장: 표지·소개·모션·Haiku 성능·Haiku 가격·크레딧·워크스페이스·마무리)에 대해 한 번에 받은 지시.
> "카드 만드는데 뭔 20분씩 걸리냐"까지 들었다. 아래는 다음 호에서 **처음부터** 지킬 것.

### A. 장 구성: "N가지가 바뀌었으면 딱 N장 보여주고 끝"
- **마무리 장 없음.** 2p 소개와 컨셉이 겹친다("네 가지 소개" ↔ "네 가지 정리"). 결론 한 줄은 **2p 마지막 두 줄**에서 닫는다.
  > 공통점은 하나입니다. 클로드가 쓰던 도구 안으로 들어옵니다. / 내 일에 닿는 것부터 한 장씩 보시면 됩니다.
- **한 주제 = 한 장.** Haiku 성능·가격을 두 장으로 나눴더니 "5페이지 삭제". 가격은 성능 장 본문 한 줄(`100만 토큰당 입력 $0.10, 출력 $0.50으로 가격도 내렸습니다`)과 부제로 합쳤다.
- **"막 페이지 수를 늘리지마."** 표지 + 소개 + N장. VOL.28 최종 6장.

### B. 링크·각주 전부 삭제
- `공식 페이지 바로가기 →` 링크 **없음** (모든 장). 출처는 make_volN.py 주석과 가이드에만 남긴다.
- 각주(`'토큰'이란?`, `'터미널 코딩'이란?`) **없음**. 필요하면 본문에 짧게 녹인다.
  - `터미널 코딩 평가(명령어 창 작업)는 0.0% → 39.2%로` ← 괄호 한 번으로 해결
- make_volN.py 의 CARDS 튜플에서 링크·각주 자리는 전부 `None`. (생성 코드는 남겨 둬도 됨)

### C. 말투: 전문경영인이 초보자에게 알려주듯
- 뼈대는 그대로 **담백한 존댓말 + 원문 수치**(§9-1 A). 거기에 장마다 **"그래서 이게 왜 중요한가" 한 줄**을 붙인다. 훈계·격언·"A보다 중요한 건 B"는 여전히 금지.
- 통과한 예:
  | 장 | 붙인 한 줄 |
  |---|---|
  | 모션 | 숫자 하나 바뀌었다고 처음부터 다시 만들 일이 없다는 뜻입니다. |
  | Haiku | 각각 48.9%, 16.4%입니다. 작은 모델의 쓰임이 넓어졌습니다. |
  | 크레딧(부제) | 직접 도구를 만들어 보라고 주는 실험 비용인 셈입니다 |
  | 워크스페이스 | 시작은 여기가 쉽습니다. 쓰던 화면을 떠날 일이 없습니다. |
- 부제가 본문 수치를 반복하면(`Max 5x $100, Max 20x $200…`) 수치는 본문에 두고 부제는 위 표처럼 **해석 한 줄**로 바꾼다 (§9-1 D "정보를 하나 더").
- 본문 6줄까지. 링크·각주가 빠진 만큼 6줄이 들어간다.

### D. 속도: 검증은 두 가지만 돌리고 바로 보고
1. 줄 길이 검사 (§9-1 G 스크립트) — 34.5 초과 0줄
2. 구조 검사 — `section`·radio·dot·`card-pageno` 수가 N으로 일치, nav prev/next CSS, 캡처 장 슬롯 `aspect-ratio` 번호
- **헤드리스 크롬 캡처로 넘침을 확인하려 하지 말 것.** 이 환경에서 `chrome --screenshot`은 `<video>`를 `<img poster>`로 바꿔도 프로세스가 안 끝난다(PNG는 떨어지지만 60초 타임아웃까지 기다림 × 장 수). 사용자가 브라우저로 직접 본다.
- 장을 지우면 **캡처 장 슬롯 비율 CSS의 카드 번호**(`#hcn-card-K .slide-media-slot`)가 밀린다. 반드시 같이 고칠 것.

## 9-4. ★★ 고정 기준 (VOL.34, 2026-11-23) — 모든 절보다 우선, `check_vol.py` 가 막는다

> "문구 AI 스럽지 않게 전문경영가가 브리프하듯이, 기자가 브리프 하듯이", "사진 고정 지금 기준으로 고정해놔".
> 기준 화면 = **VOL.34 배포본** (kikeun.github.io/weeklyai/weeklyaivol34.html).

### A. 레이아웃 고정 — 제목·사진 칸·본문 위치는 손대지 않는다
1. **제목 위치·사진 칸(16:9)·본문 위치는 템플릿(VOL.20번대) 기본값 그대로.** 매 호 같다.
2. **금지**: `cards.py` 장별 `aspect`, `EXTRA_CSS` 로 `aspect-ratio`·슬롯 `height/width/margin/padding/top/bottom`·`.slide-title/.slide-body/.slide-bottom-copy/.subkicker` 바꾸기. `EXTRA_CSS` 는 슬롯 배경색 정도만.
3. 문구가 넘치면 문구를 줄인다(§7). 칸을 줄이거나 늘리지 않는다.

### B. 사진·영상은 16:9 로 잘라 칸을 꽉 채운다
1. **모든 장 미디어 파일 = 16:9.** 레터박스(contain 여백 띠) 금지 — 영상처럼 꽉 차야 한다.
2. 자르기는 `media.py --fit16` 하나로:
   ```bash
   python $B/media.py video 원본/s03.mp4 volN/만점 --fit16 --y 44        # 인스타 720×960 녹화본 → 위 화면 720×405 (y44 = 위 검은 띠 아래)
   python $B/media.py video 원본/x.mp4 volN/장면 --ss 58 --to 70 --fit16    # 공식 영상: 16:9 아니면 가운데 기준으로 자름
   python $B/media.py img 원본/s01.jpg volN/표지.webp --fit16 --y 180      # 세로 사진 → 16:9 (y 로 보여줄 부분 선택)
   ```
   `--y`/`--x` 는 잘라낼 시작점(px). 기준 화면이 위쪽이면 `--y` 를 작게. 결과 출력에 `!! 16:9 아님` 이 나오면 다시 자른다.
3. 인스타 녹화본(720×960)은 위쪽 공식 화면만 쓴다: **`--fit16 --y 44`** (VOL.34). 첫 프레임이 빈 화면이면 `--ss 1` (포스터가 하얗게 나옴).
4. 표·차트처럼 잘리면 안 되는 자료는 **보여줄 핵심 영역을 16:9 로 골라 자른다**(contain 금지). 행이 너무 많으면 필요한 행만.

### C. 문구 = 전문경영인·기자 브리핑
1. **사실·수치로 끝나는 단문.** 한 줄 = 사실 하나. "~입니다/~했습니다" 로 담백하게.
2. **금지 표현 (AI 같다고 반려)** — `check_vol.py` 가 잡는다:
   - 해석·감상형 마무리: "~이 보입니다", "~을 보여 줍니다", "~차이를 만듭니다", "다음 과제", "~단계입니다/수준입니다/시대입니다", "~셈입니다"
   - 강조·감탄: "놀랍", "꽤", "진심으로", "무엇보다", "핵심은", "중요한 건", 느낌표·물음표
   - 구어 어미: "~죠", "~거죠", "~네요", "~답니다", "~랍니다", "응원합니다"
3-1. **★ 줄글로 잘 읽히게 (VOL.34 RV2).** "문장이 너무 짧고 뚝뚝 끊긴다", "영어 번역식 어순이라 AI가 쓴 느낌" 으로 반려.
   - 한 줄 = 한 문장이 아니다. 문장은 줄을 넘어 이어지고, 연결어미(~했고, ~했지만, ~하면서, ~해)로 이어 쓴다. 줄바꿈은 34자 폭에 맞춰 문장 중간에서 해도 된다.
   - 한국어 어순: 주어(은/는) → 내용 → 서술. "A는 X점, B는 Y점입니다" 식 나열·명사 끊기 금지 → "A가 X점으로 가장 높았고, B가 Y점으로 뒤를 이었습니다".
   - 조사를 살린다(오픈AI**의** GPT, 구글**의** Gemini). "~로, ~이며" 를 남발하지 않는다.
   - 마무리 장은 앞 내용을 반복하지 않고 새 정보(남은 내용·한계)로 쓴다. 인사말은 "고생 많으셨습니다" 로 제목·본문 통일.
3. "왜 중요한가" 한 줄이 필요하면 **해석 대신 수치 비교**로 쓴다.

   | 반려 (AI 같음) | 확정 (기자 브리핑) |
   |---|---|
   | 국어·수학·영어·한국사와 탐구 17과목까지 전부 맞혀 만점을 받았죠. | GPT-6.2 Astra와 Gemini 4 Neon이 1,276점, 전 문항을 맞혔습니다. |
   | 최상위 AI끼리는 이제 수능 점수만으로 실력을 가르기 어려운 단계입니다. | 1~4위 간 점수 차는 3점입니다. |

   | 폭넓은 지식이 지금 AI 간 차이를 만듭니다. | 과학탐구 8과목 전부 만점은 4개에 그쳤습니다. |
   | 국산 1위를 보면 지금 AI 수준이 보입니다. | 주요 결과는 네 가지입니다. |

4. **독자 = 사내 임직원.** 소스가 일반 독자(수험생 등)를 부르면 회사 맥락으로 바꾼다.
   예) "수험생 여러분, 수고 많으셨습니다" → "수험생 자녀를 두신 임직원 여러분, / 그동안 함께 마음 졸이며 고생하셨습니다." (형제·동생은 넣지 않는다, 자녀만)

### C-3. ★ 본문은 문단 문자열로, 줄바꿈은 봇이 (VOL.34 지시 "본문이 짧아서 별로", "왜 줄바꿈을 니맘대로")
1. `cards.py` 의 `body` 는 **문단 문자열 목록**으로 쓴다: `body=['첫 문장. 둘째 문장. …']`. 줄 목록을 손으로 나누지 않는다(기존 호 호환으로 줄 목록도 받기는 함).
2. `make_vol.py` 의 `wrap()` 이 자동으로 나눈다 — 어절 단위, 줄 폭 34(한글 1·영숫자 0.6), **가장 적은 줄 수 안에서 줄 길이가 가장 고르게**.
   - 영문 모델명은 끊지 않는다(Solar Mini 4.5 Preview가 → 한 덩어리).
   - "~습니다. 두"처럼 다음 문장 첫 어절이 줄 끝에 매달리지 않게 하고, 마침표·쉼표에서 끊기는 줄을 우대한다.
3. **분량은 6줄을 꽉 채운다** (장당 약 170~200자). 짧은 4~5줄 본문은 "뭔가 별로"로 반려 — 기사·원자료에서 맥락(이유·비교 수치·조건)을 한두 문장 더 넣는다. 6줄을 넘으면 문장을 줄인다.

## 11. ★ 배포(깃허브) — 단일 파일로 내장

분리형 HTML(`src="갑지.webp"`)은 **HTML만 올리면 이미지가 404**난다. 깃허브에 파일 하나만 올려도 다 보이게 하려면 **모든 로컬 미디어를 base64로 HTML에 내장**한다.

- **편집은 분리형(`_src.html`)으로**, **배포는 내장본**으로 (내장본은 base64 덩어리라 직접 편집이 어려움).
- 외부 URL(폰트 CDN, 깃허브에 호스팅된 로고 `ai54.png`)은 그대로 둬도 로딩됨.

```bash
python -c "
import re, base64, os, shutil
SRC='weeklyaivolN.html'
shutil.copyfile(SRC,'weeklyaivolN_src.html')   # 편집용 원본 백업
html=open(SRC,encoding='utf-8').read()
MIME={'.webp':'image/webp','.png':'image/png','.jpg':'image/jpeg','.gif':'image/gif','.mp4':'video/mp4'}
def repl(m):
    pre,q,val=m.group(1),m.group(2),m.group(3)
    if val.startswith(('http','data:','#')) or not os.path.exists(val): return m.group(0)
    ext=os.path.splitext(val)[1].lower()
    b=base64.b64encode(open(val,'rb').read()).decode()
    
    return f'{pre}{q}data:{MIME.get(ext,\"application/octet-stream\")};base64,{b}{q}'
html=re.sub(r'(\bsrc=)([\"\'])([^\"\']+)\2',repl,html)
open(SRC,'w',encoding='utf-8').write(html)
print('deploy size:', os.path.getsize(SRC)//1024,'KB')
"
```
- 결과: `weeklyaivolN.html`(내장·배포용) + `weeklyaivolN_src.html`(편집용).
- 내장본이 너무 크면(영상 때문) → 영상을 더 짧게 자르거나 CRF↑로 줄인 뒤 다시 내장.
- vol11 기준 내장본 ≈ 6.3MB (대부분 포켓몬 영상).

## 12. ★ 오류·해결 기록 (이 환경에서 실제로 막혔던 것)

| 증상 | 원인 | 해결 |
|---|---|---|
| `curl: (35) schannel ... CRYPT_E_NO_REVOCATION_CHECK` | 사내망 인증서 폐기 확인 실패 | `curl --ssl-no-revoke` |
| 파이썬 `urllib` 다운로드 `CERTIFICATE_VERIFY_FAILED` | 사내 TLS 가로채기 | 다운로드는 `curl --ssl-no-revoke`로 |
| curl `URL rejected: Malformed input` | 윈도 파이썬이 쓴 URL 목록에 `\r` 붙음 | `open(..., 'w', newline='\n')` |
| 헤드리스 크롬 CDP 연결 `403 Forbidden` | 원격 디버깅 origin 차단 | `--remote-allow-origins=*` |
| CDP `name 'tabs' is not defined` (크롬이 안 뜸) | 이전 크롬이 같은 프로필 폴더·포트를 잡고 있음 | **실행마다 새 `--user-data-dir` + 새 포트**. `Stop-Process`는 그룹 정책으로 막혀 있음 |
| `chrome --screenshot` 이 끝나지 않음 | 영상 자동재생 등으로 대기. **영상을 poster img로 바꿔도 안 끝남**(VOL.28) | PNG는 타임아웃 뒤에도 남아 있으니 `subprocess.run(timeout=60)` 후 파일 존재만 확인. 카드 넘침 검증 용도로는 쓰지 말 것(§9-3 D) |
| Bash 히어독 안 파이썬에서 `'\\'` 가 `'\'` 로 깨져 `unterminated string literal` | 히어독이 역슬래시를 먹음 | 역슬래시 든 스크립트는 **Write 도구로 .py 저장 후 실행** |
| Bash 히어독으로 긴 파이썬 실행 시 `unexpected EOF while looking for matching '` | 따옴표 섞인 긴 스크립트 | **Write 도구로 스크래치패드에 .py 저장 후 실행** |

## 13. 인스타 게시물을 소스로 쓸 때 (VOL.27)

"이 인스타 게시물 컨셉으로, 영상도 그대로" 요청이 오면:

1. **게시물 데이터**: WebFetch는 캡션만 준다. curl GraphQL은 금방 `Rate limit exceeded`. → **헤드리스 크롬으로 게시물 페이지를 연 뒤 `document.documentElement.outerHTML`** 을 저장하면, `<script type="application/json">` 안에 `carousel_media`(인덱스별 `video_versions` / `image_versions2`)가 들어 있다. `code == 게시물ID` 인 객체를 찾는다.
   - ⚠️ **2026-10-20 확인: 로그아웃 상태로는 로그인 벽만 온다**(미디어 데이터 0, `/embed/captioned/`도 막힘, 캡션은 `og:description`으로 받힘). → `fetch_insta.py --login` 으로 전용 프로필 `~/.weeklyai_chrome` 에 한 번 로그인해 두면 이후 헤드리스가 그 쿠키로 연다. 로그인 전이라도 캡션으로 컨셉을 잡고 미디어는 §14 공식 자료로 가면 된다.
2. **다운로드**: 각 `video_versions` 중 가장 큰 URL을 `curl --ssl-no-revoke`로 받는다. `img_index` 순서 = `carousel_media` 순서.
3. **영상 구조 파악**: 프레임을 뽑아 콘택트시트로 확인. 카드형 인스타 영상은 보통 **위쪽 = 공식 페이지 화면 녹화, 아래쪽 = 검은 바탕 자막 + 계정 워터마크**. VOL.27(ai.trend.kr): 720×960 중 **위 720×510** 만 크롭(`crop=720:510:0:0`). 표지 인물 영상은 워터마크(y≈86)·자막 칩(y≈620)을 피해 `crop=720:480:0:120`.
4. **장 매핑**: 인덱스 1:1로 대응하되, 상대 계정의 **CTA("댓글 남기면 보내드려요")·팔로우 아웃트로** 장은 버리고 우리 마무리 장으로 바꾼다.
5. **본문 소스**: 영상 자막은 OCR 대신 원문(정리본 링크 등)을 쓴다. **Notion 공개 페이지는 WebFetch·헤드리스 모두 빈 화면** → `POST https://<워크스페이스>.notion.site/api/v3/loadPageChunk` 에 `{"pageId":"<하이픈 UUID>","limit":300,"cursor":{"stack":[]},"chunkNumber":0,"verticalColumns":false}` 로 블록을 받아 텍스트화.
6. **생성 스크립트**: VOL.27부터 `make_volN.py`(카드 데이터 → `_src.html` 생성, §4 네비 8곳 자동) → `build_volN.py`(내장본). 문구 수정은 `make_volN.py`의 `CARDS` 목록에서.

## 14. 공식 영상·이미지 찾는 법 (VOL.28)

인스타 게시물이 쓴 영상은 거의 다 **앤트로픽 공식 영상의 녹화본**이다. 원본을 찾아 쓰면 화질·정당성 둘 다 좋아진다.

1. **claude.com 제품 페이지**(예 `claude.com/claude-for-google-workspace`)는 화면엔 비디오가 안 떠도(`<video src="">`), `page.html` 안 RSC 데이터에 `"videoUrl":"https://assets.claude.com/<해시>.mp4"` 와 `"youtubeId"` 가 박혀 있다. → `grep -oE 'assets\.claude\.com/[a-f0-9]+\.(mp4|webm)'` 로 뽑아 `curl --ssl-no-revoke` 로 받으면 **1080p 원본**. (VOL.28 구글 워크스페이스 영상 60초 45MB)
2. **claude.com 발표 글**(`/resources/articles/...`)은 유튜브 iframe(`youtube-nocookie.com/embed/<id>`)만 있다. → yt-dlp(§12 참고, 360p). 인스타 표지 영상(아이콘+Export)이 이 영상 68~78초 구간이었다.
3. **anthropic.com 모델 발표 페이지**(`/claude-haiku-5-5`)는 표·차트가 HTML/SVG. → `capel.py` 방식으로 요소 캡처(§12). 벤치마크표·가격표·효과/비용 차트가 각각 `table`, `svg` 요소. 페이지 인트로 아트워크는 `_next/static/media/hero_*.webp` 조각들(공식 자산이지만 조립은 내가 하는 것이라 안 씀).
4. **지원 문서**(`support.claude.com`, `platform.claude.com/docs`)는 글만 있고 그림이 없다. 수치 근거로만 쓰고, 미디어는 요금제 페이지(`claude.com/pricing?lang=en`) 카드 캡처 등으로 대신한다. 세로로 긴 카드는 핵심 구간만 잘라 쓰되 **표 비율에 맞게 슬롯 `aspect-ratio`** 를 준다(§7).
5. 매체별 신뢰 순서: 공식 페이지 자산 > 공식 유튜브 > 인스타 녹화본 상단 크롭. 인스타의 "AI Generated" 표시 이미지(VOL.28 index 5 크레딧 카드)는 쓰지 않는다.

## 16. 노래·소리가 나야 하는 호 (VOL.29, 2026-10-20 "부른 사람이 없는데 멜론 3위까지 간 노래")

인스타 ai.trend.kr/p/DeY_5snDzx8 를 그대로 옮기되 **"실제로 노래도 나와야 한다"**는 지시를 받았다.

1. **인스타 캐러셀 영상에는 오디오 트랙이 없다** (`ffprobe` 로 확인 — video 스트림만). 음악 스티커 때문이라 소리는 다른 곳에서 가져와야 한다.
2. 소리 원본은 **아티스트 공식 유튜브 MV** (`ytsearch` 로 채널명 MEOMURU 확인 → `GxChUrrY4bc`). 이 환경의 yt-dlp 는 사내 TLS 때문에 `--no-check-certificates` 가 꼭 필요하고(§12의 `--js-runtimes node --remote-components ejs:github` 도 유지), 포맷 18(640×360+AAC)만 받아진다.
3. 후렴 위치는 `fps=1/4` 콘택트시트로 잡고 `fps=2` 로 정밀 확인. 잘라낼 때 `-c:a aac -b:a 112k` + `afade` in/out 으로 뚝 끊기지 않게.
4. **재생 구조** (봇 `cards.py` 에서 `media=('sound', '이름')`, 영상은 `media.py video ... --sound` 로 자른다): 소리 장의 `<video>` 에 `data-sound` 를 두고 슬롯 안에 `.sound-btn`("♪ 소리 켜기/끄기")을 둔다. 브라우저는 사용자 조작 전 소리 자동재생을 막으므로, `pointerdown` 한 번 이후(`userActed`)부터 `template/card_script.html` 의 `syncVideos` 가 그 장을 **소리 켜고** 재생한다. 장을 넘기는 클릭 자체가 조작이라 2p 부터는 자동으로 노래가 나온다. 실패하면 무음 재생으로 돌아가고 버튼 상태만 갱신. 다른 장으로 가면 `muted=true`. 라이트박스로 확대해도 소리 유지(`openVideo(src, sound)`), 닫으면 `syncVideos()`.
5. **멜론·벅스는 사내망에서 막힌다** (`ERR_SSL_PROTOCOL_ERROR`, bugs 는 hdec.kr/warning 으로 리다이렉트). 멜론 화면이 필요하면 인스타 이미지 중 멜론 화면 부분만 크롭해서 쓴다(자막·번호 칩 제외). 유튜브 썸네일 `i.ytimg.com/vi/<id>/maxresdefault.jpg` 는 받아진다 → 갑지 배경.
6. 인스타 캡션의 차트 수치는 게시 시점 것(10/9 9위)이라 **발행일 기준 최신 보도**(10/13 3위)로 바꿨다. 근거 기사 번호는 `vol29/cards.py` 머리말에.
7. 테마 프리셋 `night`(밤 도로)를 `wai.py` 에 추가했다. VOL.29 는 봇(§15)으로 만든 첫 호.

## 18. 앱 소개 호 (VOL.32, 2026-11-09 "소문난 여섯 가지 어플")
1. 구성(지시): 앱 하나당 한 장, 소개 장은 **마지막**으로 빼서 아이콘+한 줄 정리 + 맺음말("여러분도 만들 수 있습니다"). 말투는 "AI스럽지 않게" — 딱딱한 "~합니다" 나열 대신 "주소만 열면 바로 절 마당에 들어섭니다" 식.
2. 앱 공식 자료는 **iTunes lookup API**로: `curl --ssl-no-revoke "https://itunes.apple.com/lookup?id=<앱ID>&country=kr"` → 설명·가격·버전·스크린샷 URL(`320x480bb` → `1290x2796bb` 로 바꾸면 원본). apps.apple.com 페이지는 이 PC에서 접속이 끊긴다(ECONNRESET). 검색은 `itunes.apple.com/search?term=...&entity=software`.
3. 앱 공식 영상이 없으면: 인스타 화면 녹화 상단 크롭(피클), 사용자 화면 녹화 유튜브 중 자막·버튜버 오버레이 없는 것(산사, NBT TV). 긴 유튜브는 `--download-sections "*120-200" --ffmpeg-location <imageio_ffmpeg exe>` 로 구간만.
4. 스크린샷 3장을 나란히 붙일 때 **휴대폰 위치가 다른 장은 빼기**(그늘로 산책 코스 장 반려). `vol32/원본/make_media.py`.
5. 표지 제목 일부만 강조: `headline` 줄 안에 `<em>…</em>` → 그 부분만 강조색, 2줄은 흰색 (make_vol·make_gabji 2026-11-09 지원).
6. 사실 확인으로 지시 문구를 고친 곳: "대부분 혼자 바이브코딩" → "여섯 중 셋"(피클 팀·마이모리 스타트업), Pieceful "일부 기능 유료" → "7,700원을 내고 내려받는 유료 앱".
7. 환경: python 3.15 로 바뀌며 websocket-client·imageio-ffmpeg·yt-dlp 가 빠져 있었음 → 그냥 `python -m pip install <패키지>` 로 설치됨(--trusted-host 붙이면 권한 정책에 막힘).
