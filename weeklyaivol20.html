스킬 5가지 소개

얼버무리고, 늘어지고, 어딘가 나 같지 않은 글.
그 다섯 가지를 하나씩 고쳐주는 무료 스킬입니다.

무료 · MIT 라이선스 · 설치 없이 붙여넣기만 하면 됩니다

스킬 5개, 뭘 고쳐주나

/dumbify쉬운 말로 다시 쓰기

모든 문장을 중학생도 이해할 난이도로 바꿔 씁니다. 아이디어 수준은 그대로 두고 언어만 쉬워집니다.

/storytelling계속 읽게 만드는 구조

정보를 나열하는 대신 문장을 ‘그런데’와 ‘그래서’로 잇습니다. 긴장과 반전이 생겨 끝까지 읽게 돼요.

/viral-hooks스크롤을 멈추는 첫 문장

역대 최고의 훅 100개와 비교해 내 첫 문장을 진단하고, 왜 약한지 짚어준 뒤 다시 써줘요.

/anti-aiAI 티 지우기

‘단순 X가 아니라 Y다’ 같은 화법, 돌려쓰는 단어, 줄줄이 붙는 대시를 하나하나 걷어내 줘요. 압축을 풀면 anti-ai-writing 폴더로 들어 있습니다.

/voice-dna내 목소리 입히기

내가 쓴 글 20개를 넣으면 톤·말버릇·문장 리듬이 담긴 ‘목소리 DNA’ 파일이 만들어집니다. 다섯 개 중 유일하게 직접 만드는 스킬이에요.

1채팅에 붙여넣기무료 플랜 OK · 제일 쉬움

설정이 하나도 필요 없습니다. 10초면 끝나요.

  1. 위 버튼으로 ZIP을 받아 압축을 풀어요.폴더 안에 dumbify, storytelling 같은 스킬 폴더 5개가 들어 있습니다.
  2. 쓰고 싶은 스킬 폴더를 열고 SKILL.md를 열어요.파일 우클릭 → ‘연결 프로그램’ → 윈도우는 메모장, 맥은 텍스트편집기. (voice-dna 폴더만 SKILL.md가 없습니다 — 아래 4번 참고)
  3. 내용 전체를 복사해요.윈도우 Ctrl+A → Ctrl+C / 맥 Cmd+A → Cmd+C
  4. 클로드 채팅창에 붙여넣고, 맨 아래에 한 줄만 덧붙여요.
위 스킬을 적용해서 아래 글을 다듬어줘. (여기에 내 글 붙여넣기)
알아두기무료 플랜에서도 되고 10초면 끝나지만, 새 대화를 열 때마다 다시 붙여넣어야 합니다. 여러 개를 겹쳐 쓰려면 한 대화 안에서 차례로 붙여넣으면 돼요.

2클로드 앱에 스킬 등록Pro·Max · 한 번만 설정

한 번 올려두면 매번 붙여넣을 필요가 없습니다.

  1. 클로드 앱(claude.ai)에서 설정(Settings)으로 들어가요.
  2. 기능(Capabilities) 메뉴에서 ‘코드 실행 및 파일 생성(Code execution)’을 켜요.
  3. 맞춤 설정(Customize) → 스킬(Skills) → 업로드를 눌러요.
  4. 스킬 폴더를 하나씩 ZIP으로 압축해 올려요.예: dumbify 폴더만 압축 → 업로드 → 다음은 storytelling. 폴더가 ZIP 맨 위에 오게 압축하세요.
dumbify 스킬로 이 글을 다듬어줘.
알아두기등록해 두면 이름을 부르지 않아도 클로드가 스킬 설명을 읽고 알아서 적용합니다. 다만 스킬 업로드 기능은 Pro·Max 플랜에서만 열립니다.

3클로드 코드에 설치터미널 쓰는 분

폴더째 넣어두면 모든 프로젝트에서 잡힙니다.

  1. 받은 ZIP의 압축을 풀어요.
  2. 스킬 폴더 4개를 스킬 디렉터리에 그대로 복사해요.dumbify · storytelling · viral-hooks · anti-ai-writing
  3. 클로드 코드를 새 세션으로 다시 열어요.
~/.claude/skills/
더 쉽게압축 푼 폴더를 클로드 코드에 던져놓고 이렇게 말해도 됩니다 — “이 폴더의 스킬들을 ~/.claude/skills/ 에 설치하고, 어떻게 다시 시작하면 되는지 알려줘.”

4voice-dna 만들기한 번만 · 2분

다섯 번째 스킬만 내 글로 직접 만듭니다.

  1. 내가 직접 쓴 글 20개쯤 모아요.인스타 캡션, 블로그 글, 영상 대본 다 됩니다. 많을수록 정확해요.
  2. voice-dna 폴더의 README.md를 열어 ‘프로필 생성 프롬프트’를 복사해 클로드에 붙여넣어요.
  3. 바로 아래에 모아둔 내 글 20개를 이어 붙여 보내요.
  4. 클로드가 톤·말버릇·문장 리듬·자주 쓰는 훅을 정리한 ‘목소리 프로필’을 만들어 줍니다.
  5. 그 문서를 저장해 두고, 글 다듬을 때마다 같이 붙여넣으면 끝.
내 voice-dna 프로필에 맞춰 이 글을 내 말투로 바꿔줘.

순서와 주의할 점

  • 추천 순서는 초안 → storytelling · viral-hooks(구조·첫 문장) → dumbify(쉽게) → anti-ai(AI 티 제거) → voice-dna(내 말투). 서로 충돌하지 않게 설계돼 있습니다.
  • 스킬마다 쓰기 모드와 점검 모드가 있어서, 이미 써둔 글에도 그대로 돌릴 수 있어요.
  • 스킬 원문은 영어지만 한국어 글에도 그대로 작동합니다. “한국어로 답해줘” 한 줄만 붙이면 돼요.
  • AI가 다듬은 결과는 마지막에 꼭 본인 눈으로 확인하세요. 팩트나 뉘앙스가 바뀔 수 있습니다.
  • 스킬 파일을 고쳐 나만의 버전을 만들어도 됩니다. 무료로 공개된 자료예요.
